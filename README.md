# Data Science Course

This repository is a personal collection of everything I learn, practice, and build throughout my Data Science course. It includes notes, exercises, mini-projects, and larger projects organized by topic. The goal is to track my progress, keep my work organized, and have a reference I can come back to.

## About This Repository

As I go through the course, I'll be adding code, notebooks, datasets (or links to them), and notes for each subject covered. Each topic has its own folder so everything stays organized and easy to find.


## Topics Covered

- **Python** – Fundamentals, data structures, functions, OOP, and practice exercises
- **SQL** – Queries, joins, subqueries, and database projects
- **Data Analysis** – NumPy and Pandas for data manipulation and cleaning
- **Data Visualization** – Matplotlib and Seaborn for charts and graphs
- **Machine Learning** – Supervised and unsupervised learning algorithms, model evaluation
- **Deep Learning** – Neural networks, CNNs, RNNs, and related projects
- **Statistics** – Probability and hypothesis testing fundamentals
- **Projects** – End-to-end projects that combine multiple skills

## Tools & Technologies

- **Language:** Python
- **Libraries:** NumPy, Pandas, Matplotlib, Seaborn, Scikit-learn, TensorFlow / PyTorch
- **Database:** SQL (MySQL / PostgreSQL / SQLite)
- **Environment:** Jupyter Notebook / VS Code
- **Version Control:** Git & GitHub

## How to Use This Repository

1. Clone the repository:
   ```bash
   git clone https://github.com/DashginAsgarli/data-science-course.git
   ```
2. Navigate to the topic folder you're interested in.
3. Open the notebooks (`.ipynb`) or scripts (`.py`) to see the code and notes.
